# Energy Angular Landing Page

Frontend Angular inspirado en la captura proporcionada.

## Ejecutar

```bash
npm install
npm start
```

Luego abre `http://localhost:4200`.

## Estructura

- `src/app/app.html`: estructura de la landing page.
- `src/app/app.css`: estilos responsive.
- `src/main.ts`: componente Angular standalone y datos.
- Las imágenes de ejemplo usan URLs de Unsplash; puedes reemplazarlas por imágenes locales en `src/assets`.
